—PROCESSES REDUCED

Process Reducer

reading the live process table…

Each Eco button puts a process on Windows' documented Efficiency-mode path (below-normal priority + EcoQoS power throttling) — exactly what Task Manager's “Efficiency mode” does, and everything is restored by Undo all or when OptimizeKit closes. Nothing is killed unless you press Kill on one row.

—RISK FINDINGS

Security Scan

read-only audit — press scan to run it

What is audited: antivirus real-time state, firewall per profile, every listening port and outbound connection with its owning process (RAT / bind-shell ports flagged), Run/RunOnce + Startup-folder + scheduled persistence (TEMP launchers, hidden PowerShell, IFEO debugger hijacks), executables staged in %TEMP%, double-extension droppers in Downloads, shadow-copy tampering, UAC. The scan is read-only; Revoke quarantines one entry and can put it back.

BIOS & firmware guide

read-only · OptimizeKit never writes to your firmware

Your motherboard holds performance Windows cannot reach. These settings are documented, universal and reversible — you open them yourself in the firmware setup. Restart and press Del or F2 at the brand logo.

⚠ Firmware settings are not covered by OptimizeKit's registry backup. Note your previous values before changing anything, flash the BIOS only from the vendor's official support page, and never flash during a storm, a brownout or on battery.

OptimizeKit v2.6

Windows Gaming Control Center — one static exe, embedded C++ HTTP server, liquid-glass dashboard.
34 modules · 49 reversible tweaks · 12 full themes · a Game Library of 200+ covered titles plus a built-in database of known PC games · a Process Reducer (EcoQoS) and a read-only Security Scan · a command palette (Ctrl+K) over everything · no driver, no injection, no kernel component.
Tweaks curated from Chris Titus Tech's WinUtil (MIT), Microsoft docs and the PC-gaming community. Every action logged, every key backed up, every tweak reversible.

GitHub repository WinUtil (sources)
⚠ Registry tweaks change your system — backups live in %LOCALAPPDATA%\OptimizeKit\backup_*.reg and each tweak has a per-item restore. Reboot after HAGS / timer / power-plan changes.

Appearance

Twelve complete themes. Each one redefines the background gradients, borders, glow and every control surface — not just an accent swap. Your choice is written to config.json and applied before the first frame on the next launch.
